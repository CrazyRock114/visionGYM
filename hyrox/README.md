# HYROX 官方体能赛事视觉裁判与动作动力学分析系统

本项目专门针对全球知名综合体能耐力赛事 **Hyrox（海洛克斯）全套 8 项功能性专项运动 + 跑步区间** 研发，结合高精度人体关键点骨骼估计（COCO-17 骨架拓扑结构）、生物力学动力学状态机与官方竞赛裁判规则（Hyrox Rulebook），实现自动化有效计数、违规判定（No-Rep）、动作周期分解与疲劳衰减分析。

---

## 一、 Hyrox 8 站点技术规范与裁判规则全览

| 赛事工作站 | 官方标准要求 (Hyrox Rules) | 计算机视觉判定算法 (CV Logic) | 核心度量指标 |
| :--- | :--- | :--- | :--- |
| **Station 1: 1000m SkiErg<br>(滑雪机)** | 充分发力展开，双手过头高位引手到底部完整冲程。 | 双腕垂直位移追踪、三屈三伸（髋/膝/踝）屈伸角时序分析。 | 冲程数、SPM 桨频、拉桨/回桨耗时比、发力冲程幅度。 |
| **Station 2: 50m Sled Push<br>(雪橇推)** | 维持推进动力线，持续向前蹬步。 | 肩-髋-踝躯干驱动前倾角（目标 40°-50°）、下肢高频蹬踏节奏。 | 蹬步步频、躯干驱动角、卡顿失速预警。 |
| **Station 3: 50m Sled Pull<br>(雪橇拉)** | 低重心抗阻拔河式站姿，后引拉拽。 | 质心高度变化、倒步步频与双臂后拉冲程节奏。 | 后退步频、重心稳定性、抗阻发力一致性。 |
| **Station 4: 80m Burpee Broad Jumps<br>(波比跳远)** | **① 胸部完全贴地** (Chest to Deck)；<br>**② 必须双脚同时起跳**，禁止单腿跨步。 | 1. 胸腔与地面垂直间隙检测；<br>2. 左右脚起跳时差判定（时差 > 80ms 判 **No-Rep**）；<br>3. 滞空位移估算。 | 动作次数、胸部贴地深度、跳远距离、起跳同步率。 |
| **Station 5: 1000m Rowing<br>(划船机)** | 标准发力顺序：蹬腿->伸髋->拉臂；出水躯干后仰 10°-15°。 | 膝关节角变化、双腕水平行程、出水后仰角（Layback Angle）。 | 冲程数、SPM 划船桨频、出水后仰角、四阶段时序划分。 |
| **Station 6: 200m Farmers Carry<br>(农夫行走)** | 双手持重行进，核心收紧，脊柱保持中立直立。 | 左右肩水平线差值、双侧髋关节与肩连线侧倾角（Lateral Sway）。 | 负重步频、躯干侧倾标准差、左右肩倾斜度、核心疲劳评分。 |
| **Station 7: 100m Sandbag Lunges<br>(沙袋箭步蹲)** | **① 后膝必须触及地面**；<br>**② 迈入下一步前必须双腿完全站立直立锁膝锁髋**。 | 1. 后膝最低点距地面阈值判定；<br>2. 站立双膝屈伸角检测（膝角未伸展直立判 **No-Rep**）；<br>3. 左右腿交替追踪。 | 弓步步数、后膝触地率、站立锁定角、左右腿交替对称性。 |
| **Station 8: 75/100 Wall Balls<br>(药球掷高)** | **① 屈髋折痕必须低于膝盖上缘**（深蹲深度不足判 **No-Rep**）；<br>**② 起身完全锁髋上推，药球击中目标靶**。 | 1. 膝关节内角（需小于 95°）与髋/膝垂直坐标差（$y_{hip} \ge y_{knee}$）；<br>2. 站立锁紧伸展判定。 | 墙球有效次数、No-Rep 无效次数、深蹲耗时/上推耗时、通过率。 |
| **跑步区间: 8 x 1km Running<br>(高疲劳体能跑)** | 8 组高强度力量站之间的 1km 衔接跑步。 | 双踝离地垂直高度波形、触地时间（GCT）、步频衰减率。 | 实时步频 (SPM)、触地时间 (ms)、左右对称性、体能衰减度。 |

## 二、 快速使用指南

### 1. 运行单项站点（以第 8 站墙球为例）
```bash
# 激活环境
source .venv/bin/activate

# 运行墙球演示模式（内置生物力学合成姿态流与违规注入检测）
python hyrox/main.py --station 8_wall_balls

# 分析你拍摄的真实比赛/训练视频
python hyrox/main.py --station 8_wall_balls --video /path/to/my_wall_balls.mp4
```

### 2. 支持的运动站点参数 (`--station`)
- `1_skierg`: Station 1 滑雪机
- `2_sled_push`: Station 2 雪橇推
- `3_sled_pull`: Station 3 雪橇拉
- `4_burpees`: Station 4 波比跳远
- `5_rowing`: Station 5 划船机
- `6_farmers_carry`: Station 6 农夫行走
- `7_lunges`: Station 7 沙袋箭步蹲
- `8_wall_balls`: Station 8 药球掷高
- `hyrox_run`: 跑步区间分析

### 3. 一键自动化全套跑测
```bash
# 自动依次评测全部 8 个站点及跑步区间
python hyrox/main.py --test-all
```

## 三、 输出文件结构

每次分析运行完成后，系统会在 `hyrox/data/output/<站点名称>_<时间戳>/` 目录下生成：
1. **`*_annotated.mp4`**：包含左侧人体姿态高亮骨架、违规警示横幅与右侧专业暗黑风格数据看板（Side Panel）的高清合成视频。
2. **`analysis.png`**：包含单次动作耗时分布（绿柱有效 / 红柱违规）、动作节奏变化与疲劳拟合线的综合图表。
3. **`summary.txt`**：文字版裁判执裁报告，列出总评、达标率及每次动作的判罚明细。
4. **`analysis.json`**：结构化 JSON 数据，方便与下游训练管理后台集成。
